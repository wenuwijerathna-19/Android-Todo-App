# Android Todo App

## Overview

Android Todo App is a mobile application developed using Kotlin and Android Studio. The application allows users to create, manage, update, and organize daily tasks efficiently through a simple and user-friendly interface.

## Features

* Add New Tasks
* Edit Existing Tasks
* Delete Tasks
* Task Management
* Simple and User-Friendly Interface

## Technologies Used

* Kotlin
* Android Studio
* XML Layouts
* Gradle

## How to Run

1. Clone the repository.
2. Open the project in Android Studio.
3. Sync Gradle files.
4. Build and run the application on an Android emulator or physical device.
